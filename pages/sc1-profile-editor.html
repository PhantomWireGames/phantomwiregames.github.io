Back up the original before you overwrite it.

0x68 difficulty 00 0x7D8 progress 00 size 0 bytes
Progress is the index of the furthest unlocked mission, so 0 is Training only and 11 unlocks everything. The map table at 0x2C4 is static and carries no progress. Everything else in the file is uninitialised memory and is left untouched.

Elite and permadeath come from Enhanced SC, which also writes profiles in its own format. Enhanced SC saves and stock saves are not interchangeable, and each build hides the other's. Setting Elite or permadeath on a stock profile will not make the stock game understand them.
