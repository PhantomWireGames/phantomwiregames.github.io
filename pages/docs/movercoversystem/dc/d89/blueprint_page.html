Mover Cover System 1.1
Cover system for Unreal Engine's Mover
Blueprint Reference

Callable Functions

TryEnterCover

Fires a sphere sweep from the character's forward vector. On hit, populates FCoverModeInputs and sets bShouldBeInCoverMode, triggering UCoverEntryTransition. Returns true if cover was entered. Call from your cover input action.

ExitCover

Clears cover state and clears bShouldBeInCoverMode, triggering UCoverExitTransition. Call on input release.

UpdateCoverWall (float LateralInput)

Must be called every tick while in cover, passing the player's lateral axis value (-1..1). Runs depth tracking, head classification, lookahead, edge detection, floor checks, corner probing, and gap scanning.

SetWantsToAim (bool bAiming)

Triggers a peek out to the wall edge when at an edge with no wall ahead. Pass true on aim press, false on release.

RequestGoAroundCorner

Drives the character to the detected corner point and transitions wall data to the new wall on arrival. Only takes effect when bIsAtCorner is true and the character is not aiming.

RequestGapMovement

Triggers movement to the detected gap wall. Uses spin speed for short gaps (GapDistance < GapSprintThreshold) and sprint speed for long gaps, with the character rotating to face the travel direction during a sprint. Only fires when bGapDetected is true and the player holds lateral input toward the gap. Aiming blocks gap movement. Call from the same input action as RequestGoAroundCorner.

AddCoverInputsToCollection

Injects FCoverModeInputs into the Mover input collection. Call from ProduceInput each tick while bIsInCover is true.

Movement Mode Transitions

Cover entry and exit are driven through Mover's transition system rather than direct QueueNextMode calls. This ensures both client and server make the same mode switch at the same simulation tick via the replicated FCoverModeInputs struct.

Class Add to Target Mode When it fires
UCoverEntryTransition Walking mode Cover bShouldBeInCoverMode = true
UCoverExitTransition Cover mode Walking bShouldBeInCoverMode = false
