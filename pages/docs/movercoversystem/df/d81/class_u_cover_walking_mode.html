Detailed Description

Mover movement mode that constrains the character to a cover surface.

Only GenerateMove_Implementation is overridden to replace free 2D walking intent with cover-locked lateral movement, wall depth correction, edge peeking, corner transitions, and wall-facing rotation.

Requires an FCoverModeInputs entry in the Mover input collection each tick, written by UMoverCoverComponent::AddCoverInputsToCollection from ProduceInput.

Register this mode on your MoverComponent with the name matching UMoverCoverComponent::CoverModeName (default: "Cover").
