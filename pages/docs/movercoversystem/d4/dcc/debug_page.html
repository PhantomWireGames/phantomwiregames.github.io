Mover Cover System 1.0.0
Cover system for Unreal Engine's Mover
Debug Tools

Editor Visualization

Enable the Cover Debug toggle in the viewport toolbar (View Modes dropdown). The subsystem scans surfaces near the editor camera every 0.5 s and tints static mesh geometry using M_CoverDebugOverlay:

  • Green - full cover (surface top >= HeadTraceHeight)
  • Yellow - half cover (surface top >= HeadTraceHeight x 0.5)
  • Red - too low
Note
Requires /MoverCoverSystem/Materials/M_CoverDebugOverlay to exist. Create an Unlit / Translucent material with a Vector Parameter named Color wired to Emissive and Opacity Alpha.
