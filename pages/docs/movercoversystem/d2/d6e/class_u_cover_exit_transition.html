Detailed Description

UCoverExitTransition

Add this to the Cover movement mode's Transitions list. Fires when FCoverModeInputs.bRequestCoverExit is true, transitioning back to Walking. Same networking rationale as UCoverEntryTransition — driven by replicated input data so both client and server transition at the same simulation tick.
