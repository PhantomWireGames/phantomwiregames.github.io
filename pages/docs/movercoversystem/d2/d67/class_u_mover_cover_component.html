Detailed Description

Actor component that adds full cover behaviour to any Mover-based character.

Drop this onto your Mover pawn to get cover detection, wall tracking, edge/corner probing, aim-peeking, and concave-corner auto-transition — all driven through the Mover input collection with no character-class dependencies.

Setup

  1. Add this component to your Mover character Blueprint or C++ class.
  2. In your character's ProduceInput override, call AddCoverInputsToCollection and pass the InputCollection reference from BreakStruct MoverInputCmdContext.
  3. Add UCoverWalkingMode to your MoverComponent's movement mode list and name it to match CoverModeName (default: "Cover").
  4. Bind your input actions to TryEnterCover, ExitCover, UpdateCoverWall, SetWantsToAim, and RequestGoAroundCorner.
