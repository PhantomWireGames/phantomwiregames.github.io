Detailed Description

EXPERIMENTAL

Editor subsystem that classifies cover surfaces in the level and applies colored debug materials directly to static mesh geometry.

Activated via the "Cover Debug" toggle in the viewport toolbar, or by setting the console variable r.MoverCover.ShowCoverDebug to 1.

The scan fires automatically every 0.5 s, centred on the active editor viewport camera. Scanned surfaces are classified by bounds height relative to HeadTraceHeight and tinted with M_CoverDebugOverlay:

Green = full cover (surface top >= HeadTraceHeight) Yellow = half cover (surface top >= HeadTraceHeight * 0.5) Red = too low (surface top < HeadTraceHeight * 0.5)

Original materials are restored when the CVar is toggled off or on the next rescan if cover type has not changed.

Note
Requires the material /MoverCoverSystem/Materials/M_CoverDebugOverlay to exist in the plugin Content folder. Create a simple Unlit material with a Vector Parameter named "Color" wired to Emissive.
