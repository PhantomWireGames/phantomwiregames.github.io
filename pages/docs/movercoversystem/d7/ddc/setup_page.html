Mover Cover System 1.1
Cover system for Unreal Engine's Mover
Setup Guide

Video Tutorial: www.youtube.com/watch?v=fbDXHUWPKEw

Step 1 - Register the Movement Mode

Add cover to your movement mode enum. Open your character Blueprint and select the CharacterMover component. In the Details panel, find Movement Modes and add a new entry. Set the mode class to Cover Walking Mode and the name to exactly Cover. This name must match UMoverCoverComponent::CoverModeName (default: "Cover").

Step 2 - Add the Component

In your character Blueprint's Components panel, click Add and search for Mover Cover Component. All detection parameters are configurable from the Details panel without touching code.

MoverCover component added to character and selected with Config and UI settings visible

Step 3 - Wire ProduceInput

Override ProduceInput in your character Blueprint (or open the existing override). After the existing Add Data To Collection calls, add Add Cover Inputs To Collection targeting the MoverCover component and passing the InputCollection pin. This injects FCoverModeInputs into the Mover simulation each tick so UCoverWalkingMode can read wall data during GenerateMove.

Add Cover Inputs To Collection wired at the end of ProduceInput

Step 4 - Create Input Actions

The plugin includes IA_Cover, IA_CoverCorner, and IMC_Cover ready to use. If wiring manually, the minimum required actions are:

Action Suggested key (KB) Suggested key (Gamepad)
IA_Cover F Right Shoulder
IA_CoverCorner E Face Button Top (Y/△)
Note
IA_CoverCorner handles both corner go-around and gap movement — the same input key triggers whichever is available at the current edge.
IA_Cover and IA_CoverCorner mapped in the Input Mapping Context

Step 5 - Bind Input Actions in the Character

Wire the input actions to the MoverCover component in your character's Event Graph:

Cover enter / exit - toggle on IA_Cover triggered:

IA_Cover: branch on bIsInCover to call ExitCover or TryEnterCover

Shimmy (move while in cover) - on IA_Move triggered:

IA_Move: call UpdateCoverWall with the lateral input axis while bIsInCover

Aim / peek - on IA_Aim triggered (pass Action Value bool):

IA_Aim: call SetWantsToAim - also feeds your existing WantsToAim input state

Go around corner / gap movement - on IA_CoverCorner triggered: Call both RequestGoAroundCorner and RequestGapMovement from this action. Each function checks its own conditions internally — RequestGoAroundCorner only fires when bIsAtCorner is true, and RequestGapMovement only fires when bGapDetected is true and the player holds input in the gap direction.

IA_CoverCorner: call both RequestGoAroundCorner and RequestGapMovement

Jump / exit cover - call ExitCover before your existing jump logic so the character leaves cover before attempting a jump or traversal:

IA_Jump: ExitCover called first, then normal jump / traversal logic

Step 6 - Handle Crouch via OnCoverCrouchChanged

Bind the On Cover Crouch Changed delegate in BeginPlay. In the bound event, set WantsToCrouch in your custom inputs struct to the bShouldCrouch parameter value. Your existing OnPreSimulateTick crouch handling picks it up naturally - no separate crouch logic needed.

Note
bShouldCrouch is true in half cover when not aiming, and false in full cover or when aiming over a half-wall. The component also calls Crouch() / UnCrouch() directly so it works even without the delegate wired.
