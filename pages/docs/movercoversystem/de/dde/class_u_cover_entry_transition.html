Detailed Description

UCoverEntryTransition

Add this to the Walking movement mode's Transitions list. Fires when FCoverModeInputs.bRequestCoverEntry is true, transitioning to Cover mode. Because FCoverModeInputs is NetSerialize'd, both client and server read the same flag and make the same decision - keeping them in sync without relying on imperative QueueNextMode calls from game-thread code.
