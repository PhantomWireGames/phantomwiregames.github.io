Detailed Description

Registers FCoverModeInputs::NetSerialize with the engine so that the custom serialization implementation is actually called during network replication. Without this trait, the engine uses a fallback path that ignores NetSerialize, causing bit layout mismatches between client and server (FBitReader overflows).
