Detailed Description

Registers the "Icon Font" level editor toolbar button and the dockable tab it opens (SEasyIconFontWindow).

Replaces the old per-project Editor Utility Widget + "Execute Python Command" Blueprint node setup - this module calls the same Python backend (Content/Python/easy_icon_font.py) directly via IPythonScriptPlugin instead.
