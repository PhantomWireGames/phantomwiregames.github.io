Detailed Description

One entry in the preview bar.

Either a font glyph (MonoVector/ColorVector, has a codepoint) or a texture (has a brush wrapping the loaded UTexture2D). Parsed straight from the <font>.codepoints.json registry sidecar written by easy_icon_font.py.
