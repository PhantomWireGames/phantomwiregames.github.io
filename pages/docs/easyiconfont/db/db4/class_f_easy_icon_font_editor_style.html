Detailed Description

Registers the plugin's editor-only icon brushes (currently just the toolbar button icon).

A minimal FSlateStyleSet singleton, same pattern most plugins use for custom editor icons. Call Initialize() once at module startup and Shutdown() at module shutdown; Get() returns the registered style name to pass into FSlateIcon(FEasyIconFontEditorStyle::GetStyleSetName(), "EasyIconFont.ToolbarIcon").
