Detailed Description

One row per icon in the IconGlyphTable DataTable.

Keyed by RowName (== GlyphName, e.g. "icon_bell"). Built by the plugin's Python tooling (export_registry_to_csv) - hand-editing is fine too, this is a plain DataTable row.
