Detailed Description

The Easy Icon Font tool window.

Replaces the old per-project Editor Utility Widget. Collects the same inputs the EUW did (source image, font paths, glyph name, glyph type) and calls straight into Content/Python/easy_icon_font.py via IPythonScriptPlugin, same backend as before, just invoked from C++ instead of a Blueprint "Execute Python Command" node. A preview bar along the bottom shows every icon currently registered against the font path in the "Font file" field, read directly from its .codepoints.json registry sidecar.
