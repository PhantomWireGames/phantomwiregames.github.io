Detailed Description

Displays a single icon looked up by name from IconGlyphTable.

Instead of requiring a raw glyph character or a texture reference to be wired up by hand per placement, this widget resolves everything from a single GlyphName lookup.

Handles all three EIconGlyphType representations transparently: MonoVector and ColorVector both just set a character on the bound Text Block (COLR color, where present, is baked into the font itself

  • the widget doesn't need to know the difference); Texture swaps to a bound Image widget instead. Callers only ever set GlyphName.
Setup (per-project, one-time)
  1. Build your icon font / textures with the plugin's Python tooling and export the registry to CSV.
  2. Import that CSV in the Content Browser as a DataTable, row struct FIconGlyphRow.
  3. Assign that DataTable to every UIconTextWidget instance's IconGlyphTable property (or subclass this Blueprint-side and hardcode it there once).
Usage (per-placement)
Drop a UIconTextWidget (or your Blueprint subclass) wherever you'd otherwise place a Text Block or Image showing an icon. Set GlyphName to e.g. "icon_bell" - the widget resolves which representation to show.
Note
Requires a UMG designer-side Text Block named "IconText" (BindWidget) in any Blueprint widget built on top of this. An Image named "IconImage" is optional (BindWidgetOptional) - only needed if any row you'll actually display uses GlyphType::Texture.

◆ IconFontStyle

FSlateFontInfo UIconTextWidget::IconFontStyle

Font, size, color, etc. for MonoVector/ColorVector icons.

Set the Font Family here to your composite icon Font asset, same as any normal Text Block. For ColorVector rows the baked-in COLR palette wins over this style's color; for MonoVector rows this color tints the glyph as usual. For Texture rows, only Size is used (as a square brush size, so texture icons visually match glyph icons at the same setting) - Font/Color are ignored.

BindWidgetOptional: the Image that renders Texture-type rows.

Add an Image named exactly "IconImage" only if this placement (or this project) will ever show a Texture-type row. If a Texture row is looked up on a widget instance with no IconImage bound, RefreshIcon falls back to the "?" glyph rather than silently showing nothing.
