Easy Icon Font 1.0
UE5 editor plugin that converts PNG/SVG/WEBP icons into font glyphs.
Troubleshooting

Icon Shows a "Private Use" Placeholder Box

This means the codepoint isn't resolving to a real glyph where it's being displayed, even though the font file itself may be fine.

Most common cause: the FontFace asset's source path has drifted from the font file you're actually editing. This happens automatically the first time the plugin is used in a NEW project - the FontFace asset ships bundled with the plugin, and its recorded source path is whatever was true in the project it was ORIGINALLY created in, which is meaningless anywhere else.

Try this first: click Setup. It now automatically points EasyIconFontFace at this project's own font file as one of its steps, which resolves this exact situation in most cases without anything manual.

If that doesn't fix it: right-click the FontFace asset in the Content Browser and Reimport manually to force it to re-read the current file. Worth doing after any Add Icon too if a newly added icon isn't showing up, in case the asset's source path is pointing somewhere unexpected for a reason Setup's automatic fix doesn't cover.

The broken placeholder box shown when a codepoint doesn't resolve

Icons Disappeared After a Plugin Update

The plugin ships a blank template font (EasyIconFont_Blank.ttf) that's safe to overwrite on every update. Your actual working font (EasyIconFont.ttf) is never shipped in an update, so it shouldn't be possible for an update to silently reset it. If it still does not exist, click Setup to recreate it from the template.

Color Vector Limitations

  • Raster sources only - there's no SVG-native Color Vector path yet. A multi-fill SVG needs to be handled as Mono Vector (if it's actually single-color) or Texture.
  • No detection of "this source is unsuitable" - a photographic or gradient-heavy image will still vectorize, just poorly (blocky, over-simplified). Re-add it as Texture explicitly if that happens.
  • Requires numpy and scikit-image in addition to fontTools and Pillow - the status light and Setup button cover this.

DataTable Isn't Updating

Confirm the DataTable field actually points at an existing DataTable asset with row struct FIconGlyphRow - the auto-sync only refreshes an existing DataTable's rows, it doesn't create one.
