Easy Icon Font 1.0
UE5 editor plugin that converts PNG/SVG/WEBP icons into font glyphs.
How to Use

Opening the Tool

Click the Icon Font button on the level editor toolbar, or open it from Window > Easy Icon Font if the toolbar button isn't visible on your layout.

The Icon Font button on the level editor toolbar

Running Setup

The status light at the top of the window shows whether the tool is ready to use:

  • Green - required Python packages are installed and the working font file exists.
  • Red - hover the light for exactly what's missing.

Click Setup to fix all of this in one step: it installs any missing packages (fontTools, numpy, scikit-image, Pillow) into UE's embedded Python interpreter, creates Resources/EasyIconFont.ttf from the bundled blank template if it doesn't exist yet, and points the EasyIconFontFace asset at that file - the last part matters most the first time you use the plugin in a new project, see Icon Shows a Private Use Placeholder Box if you ever see that happen. This can take a minute or two the first time and will freeze the editor UI while it runs.

The status light and Setup button, red and green examples

Adding an Icon

Fill in the fields and click Add Icon:

Field What it is
Source image Path to the .svg, .png, or .webp you're adding
Font file (.ttf) The working font on disk - defaults to the plugin's own Resources/EasyIconFont.ttf
Font asset path The FontFace asset to reimport after building the glyph
Texture folder Where Texture-type icons get imported to
DataTable Optional - auto-reimports this DataTable from the CSV after every add
Glyph name A stable, descriptive name (e.g. icon_bell) - this is the RowName other systems look it up by
Glyph type Auto, Mono Vector, Color Vector, or Texture - see below
The full field stack filled in with example values

Glyph Type

  • Auto - .svg sources become Mono Vector. Anything else (PNG/WEBP) attempts Color Vector first, falling back to Texture only if that attempt fails.
  • Mono Vector - a single flat-fill SVG, extruded into a real glyph outline. Infinitely scalable, tinted by whatever text color it's displayed with.
  • Color Vector - a flat, limited-palette raster source, traced and rebuilt as a multi-layer COLR/CPAL glyph. Still infinitely scalable, but its color is baked in rather than tinted.
  • Texture - a plain UTexture2D import, for source art that doesn't vectorize cleanly (gradients, photographic detail).
The Glyph Type dropdown open, showing all four options

Reading the Preview Bar

The strip along the bottom shows every icon currently registered against the font in the Font file field, read live from its .codepoints.json registry sidecar. Click any icon there to fill the Glyph name field with its name, instead of retyping it.

The preview bar showing Mono Vector, Color Vector, and Texture icons

Removing an Icon

Type or click an icon's name into Glyph name, then click Remove Icon. For Mono/Color Vector icons this strips the glyph out of the font entirely (cmap entry, outline, and - for Color Vector - every layer glyph). For Texture icons it only unregisters the entry; the actual texture asset is left alone.

Glyph name filled in via a preview click, ready for Remove Icon

What's Already Set Up

The plugin ships with everything wired and ready to go - nothing needs creating from scratch:

Asset Purpose
/EasyIconFont/EasyIconFontFace The FontFace asset - already the default in the Font asset path field
/EasyIconFont/EasyIconFont The composite Font asset built on top of it
/EasyIconFont/DT_EasyIconFont_Glyphs The DataTable - already the default in the DataTable field, keeps itself in sync automatically
/EasyIconFont/EasyIconFont_RichTextDecorator A ready-to-use decorator instance - just add it to a RichTextBlock's Decorators array, no configuring needed
/EasyIconFont/WBP_Icon A ready-to-use IconTextWidget Blueprint - drop it into your UI and set GlyphName

Just click Setup, then start adding icons - the fields above are already pointed at the right places.
