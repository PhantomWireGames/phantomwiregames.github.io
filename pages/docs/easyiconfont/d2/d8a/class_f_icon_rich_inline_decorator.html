Detailed Description

The actual per-run decorator logic.

Created fresh by UIconRichTextDecorator::CreateDecorator for each RichTextBlock that uses it. Mirrors IconTextWidget::RefreshIcon's branching (glyph character vs texture image) but builds a standalone inline SWidget instead of populating BindWidget members.
