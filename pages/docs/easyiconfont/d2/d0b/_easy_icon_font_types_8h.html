enum class EIconGlyphType : uint8
strong

How a single icon row is actually represented.

UIconTextWidget branches on this to decide whether to show a font glyph or a texture - see its RefreshIcon().

Enumerator
UMETA 

Single-color glyph outline (glyf table).

Tinted by the TextBlock's own color-and-opacity, same as any normal text. Used for icons that started as a flat single-fill SVG path.

UMETA 

Multi-color glyph built from layered outlines + a COLR/CPAL palette.

Colors are baked into the glyph itself, NOT tinted by the TextBlock. Used for flat, limited-palette icon art that has more than one fill color (multi-fill SVG, or a quantized/traced PNG or WEBP). Renders through the exact same TextBlock as MonoVector; the widget doesn't need to distinguish the two at runtime, only the font-build tooling does.

UMETA 

Plain raster fallback for source art that doesn't vectorize cleanly.

For gradients, soft shadows, photographic detail. No font involved; rendered via a bound Image widget instead of the glyph TextBlock.
