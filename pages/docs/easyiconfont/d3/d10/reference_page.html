Easy Icon Font 1.0
UE5 editor plugin that converts PNG/SVG/WEBP icons into font glyphs.
Widget & Rich Text Reference

IconTextWidget

Displays a single icon looked up by name from an IconGlyphTable. /EasyIconFont/WBP_Icon is a ready-to-use Blueprint built on this - drop it straight into your UI and set GlyphName, no further setup needed. To build your own on top of the base class instead, it requires a UMG Text Block named exactly IconText (BindWidget); an Image named IconImage is optional, only needed if the table has any Texture-type rows.

Property Purpose
GlyphName Which icon to show - matches a RowName in IconGlyphTable
IconGlyphTable The DataTable built from the plugin's export step
IconFontStyle Font/size/color for Mono/Color Vector icons; Size also drives Texture icon size
Note
For Color Vector rows, the font's baked-in COLR palette wins over IconFontStyle's color.

IconRichTextDecorator

Lets a RichTextBlock show icons inline with text:

Press <icon id="icon_jump" size="48" color="#FF3B30"/> to jump!

/EasyIconFont/EasyIconFont_RichTextDecorator is a ready-to-use instance already pointed at the plugin's DataTable and font - just add it to a RichTextBlock's Decorators array. To configure your own instead, assign IconGlyphTable/IconFontStyle the same way as on an IconTextWidget.

Attribute Required Purpose
id Yes The glyph name to display
size No Overrides IconFontStyle.Size for this one instance
color No Overrides IconColor for this one instance - #RGB, #RGBA, #RRGGBB, or #RRGGBBAA
Warning
color has no effect on Color Vector icons - their color is baked into the font itself via COLR/CPAL.

FIconGlyphRow / DataTable

One row per icon, keyed by RowName. Columns: GlyphType (MonoVector / ColorVector / Texture), Codepoint (font rows only), Texture (Texture rows only, a soft object reference).
