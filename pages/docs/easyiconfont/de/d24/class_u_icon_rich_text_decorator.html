Detailed Description

Lets a RichTextBlock show icons inline with text via custom markup.

Press <icon id="icon_jump"/> to jump!

Add an instance of this class to the RichTextBlock's Decorators array (Details panel), then assign IconGlyphTable/IconFontStyle the same way you would on an IconTextWidget. Renders through the exact same FIconGlyphRow lookup and the same three representations (MonoVector/ColorVector as a styled inline character, Texture as an inline image) - an icon looks identical whether it's placed via IconTextWidget or inline in rich text.

Note
The tag's "id" attribute is the glyph name (matches the DataTable's RowName), same as GlyphName on IconTextWidget. Optional per-tag "size" and "color" attributes override IconFontStyle.Size and IconColor for that one instance, e.g.
<icon id="icon_bell" size="48" color="#FF3B30"/>

◆ IconColor

FLinearColor UIconRichTextDecorator::IconColor = FLinearColor::White

Default tint for MonoVector icons (and a multiply-tint for Texture icons).

Overridable per tag via the "color" attribute, e.g. <icon id="icon_bell" color="#FF3B30"/>. White (the default) means "no tint, show the icon exactly as drawn/imported".

Warning
Has NO effect on ColorVector icons - their color is baked into the font itself via COLR/CPAL, same limitation as IconTextWidget.

◆ TagName

FName UIconRichTextDecorator::TagName = FName(TEXT("icon"))

The inline tag name this decorator responds to.

Markup looks like <TagName id="glyph_name"/>. Defaults to "icon"; change this if you're adding more than one icon decorator instance (e.g. a separate table/style for a different icon set) to the same RichTextBlock and need them to respond to different tags.
